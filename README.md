A lightweight, responsive web application built with Python and Flask that integrates the high-speed Groq API to provide real-time conversational AI responses through a clean custom browser interface.

## 🚀 Features
* **Interactive Interface:** A user-friendly chat layout built with HTML and CSS for seamless prompt submission.
* **High-Speed AI Inference:** Powered by the Groq API to deliver near-instantaneous text generation and conversational responses.
* **Secure Key Management:** Utilizes `python-dotenv` to keep private API keys hidden and uses a robust `.gitignore` setup to prevent credential leaks.
* **Modular Structure:** Clean separation of frontend templates, static styling, and backend logic.


## 🛠️ Tech Stack
* **Language:** Python
* **Web Framework:** Flask
* **AI Engine:** Groq API SDK
* **Frontend:** HTML5, CSS3
* **Version Control:** Git & GitHub
